## 1. الطرفية وPowerShell: شيئان مختلفان

تطبيق الطرفية (Terminal) هو النافذة التي تكتب فيها الأوامر وتقرأ النتائج. أما PowerShell فهو الصدفة (Shell): البرنامج الذي يستقبل الأمر ويفسره وينفذه.

مستكشف الملفات (File Explorer) يعرض الملفات بصرياً. الطرفية تمنحك طريقة نصية للتعامل معها. كلاهما يتعامل مع ملفات الجهاز، لكن بأسلوب مختلف.

في هذا الدرس سنستخدم أوامر PowerShell على Windows. افتح PowerShell على جهازك ونفّذ الأوامر بنفسك؛ لا شيء هنا ينفذ تلقائياً.

- Terminal = نافذة إدخال وإخراج.

- PowerShell = Shell يفسر الأوامر.

- File Explorer = واجهة رسومية للملفات والمجلدات.

```powershell
Get-Location
```

> هذا أمر PowerShell. الطرفية تعرض ما يطبعه PowerShell بعد تنفيذ الأمر.

## 2. ما هو المجلد الحالي؟

عندما تفتح PowerShell، تكون الأوامر مرتبطة بمجلد حالي. تخيله المكان الذي تقف فيه الآن. إذا طلبت إنشاء ملف باسم notes.txt دون كتابة مسار كامل، فسيُنشأ داخل هذا المجلد.

لمعرفة مكانك استخدم Get-Location. يوجد له اختصار شائع هو pwd. كلاهما يعرض المسار الحالي.

- المجلد الحالي يؤثر في معنى المسارات النسبية.

- اعرف مكانك قبل إنشاء الملفات أو التنقل.

```powershell
Get-Location
```

> المسار الذي سيظهر عندك قد يختلف. القيمة C:\Users\Learner مثال فقط، والمهم أن تتعرّف على شكل المسار.

## 3. عرض الملفات والمجلدات

استخدم Get-ChildItem لعرض العناصر الموجودة داخل المجلد الحالي. الاختصارات dir وls تعمل أيضاً في PowerShell.

قد ترى مجلدات وملفات في النتيجة. المجلد يمكن أن يحتوي عناصر أخرى، بينما الملف يحتوي بيانات مثل نص أو صورة أو شيفرة.

- Get-ChildItem أو dir لعرض المحتويات.

- الاسم وحده لا يخبرك دائماً بنوع العنصر؛ انتبه إلى كونه مجلداً أو ملفاً.

```powershell
Get-ChildItem
```

> يعرض هذا الأمر محتويات المجلد الذي تقف بداخله الآن.

## 4. المسار المطلق والمسار النسبي

المسار (Path) هو عنوان يحدد مكان ملف أو مجلد. المسار المطلق يبدأ من جذر القرص، مثل C:\Users\Learner\Documents. لذلك يحدد المكان دون الاعتماد على مجلدك الحالي.

المسار النسبي يصف مكاناً انطلاقاً من المجلد الحالي. مثلاً Documents\Rust يعني مجلد Rust الموجود داخل Documents بالنسبة إلى موقعك الحالي.

النقطة . تعني المجلد الحالي، والنقطتان .. تعنيان المجلد الأب. أما .\notes.txt فيعني الملف notes.txt الموجود في المجلد الحالي.

- C:\Users\Learner\Documents = مسار مطلق.

- Documents\Rust = مسار نسبي.

- .. = المجلد الأب، و . = المجلد الحالي.

```powershell
Set-Location ..
```

> ينقلك إلى المجلد الأب للمجلد الحالي. الاختصار هو cd ..

## 5. التنقل بين المجلدات

استخدم Set-Location لتغيير المجلد الحالي. الاختصار cd يؤدي الغرض نفسه. إذا كان اسم المجلد يحتوي مسافة، ضعه بين علامتي اقتباس.

مثال: cd Documents ينقلك إلى مجلد Documents الموجود داخل مجلدك الحالي. و cd "Project Files" ينقلك إلى مجلد اسمه Project Files.

- cd اسم_المجلد = الدخول إلى مجلد داخلي.

- cd .. = الرجوع إلى المجلد الأب.

- cd . = البقاء في المجلد الحالي.

```powershell
Set-Location "Project Files"
```

> علامتا الاقتباس تجعلان المسافة جزءاً من اسم المجلد بدلاً من فصل الأمر إلى أجزاء.

## 6. الملفات والامتدادات

الملف عنصر يخزن بيانات. غالباً يتكون الاسم من اسم أساسي وامتداد بعد آخر نقطة. في notes.txt الاسم notes والامتداد txt. وفي main.rs الامتداد rs الذي نستخدمه لملفات مصدر Rust.

انتبه: report.rs.txt امتداده الأخير txt، وليس rs. الامتداد يساعد البرامج والمستخدم على معرفة نوع الملف، لكنه لا يحوّل محتوى الملف تلقائياً إلى ذلك النوع.

قد يخفي Windows الامتدادات المعروفة في مستكشف الملفات. لذلك قد ترى notes بدلاً من notes.txt. يمكنك تفعيل File name extensions من قائمة View في File Explorer.

- main.rs ملف شيفرة Rust.

- Cargo.toml ملف إعدادات مشروع Cargo.

- الامتداد هو الجزء بعد آخر نقطة في اسم الملف.

```powershell
New-Item -ItemType File -Name "notes.txt"
```

> ينشئ ملفاً فارغاً اسمه notes.txt في المجلد الحالي. لا يكتب محتوى بداخله.

## 7. إنشاء مجلد وملف

لإنشاء مجلد استخدم New-Item -ItemType Directory -Name "RustPractice". يوجد اختصار أبسط هو mkdir RustPractice.

بعدها ادخل إليه باستخدام cd RustPractice، ثم أنشئ ملفاً داخله باستخدام New-Item -ItemType File -Name "notes.txt".

في التمرين العملي أدناه، نفّذ الأوامر في PowerShell على جهازك واحدة تلو الأخرى. يمكنك كتابة الاختصار أو الأمر الكامل، ثم عرض المحتويات للتأكد من النتيجة.

- أنشئ المجلد أولاً.

- ادخل إلى المجلد قبل إنشاء الملف.

- اعرض المحتويات للتأكد من مكان الملف.

```powershell
mkdir RustPractice
```

> ينشئ مجلداً فرعياً باسم RustPractice داخل المجلد الحالي.
