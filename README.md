# RustPath

RustPath منهج عملي لتعلّم لغة Rust من الصفر، بواجهة عربية وإنجليزية. يبدأ بفهم أساسيات البرمجة والكمبيوتر، ثم ينتقل إلى بيئة Rust ومفاهيم اللغة وينتهي بمشاريع عملية. الموقع مساحة تعلّم ثابتة مبنية باستخدام HTML وCSS وJavaScript: الشرح والتمارين والاختبارات تعمل داخل الصفحة، مع مختبر أوامر افتراضي للدرس الحالي. لا يحتاج إلى npm أو أداة بناء أو خادم تطبيقات. يمكن تبديل الواجهة بين العربية RTL والإنجليزية LTR، ويُحفظ اختيار اللغة في المتصفح.

## بنية المستودع

- `docs/` — ملفات الموقع الثابت وصفحة عرض سجل التقدم.
- `docs/progress.json` — المصدر المنظم الوحيد لحالة العناصر الـ43 وأدلتها.
- `LEARNING_PROGRESS.md` — السجل المقروء وقواعد التدريس وملاحظات التقدم.
- `lessons/` — محتوى الدروس المنظم، وتُنسخ ملفات الدروس المستخدمة إلى موقع Pages وقت النشر.
- `docs/lesson.html`, `docs/lesson.js`, `docs/lesson.css` — مساحة التعلّم والتفاعل داخل الصفحة.
- `scripts/validate-lessons.mjs` — التحقق من بنية محتوى الدروس والاختبارات.
- `projects/` — مشاريع Rust التدريبية المستقلة.
- `scripts/validate-progress.mjs` — مدقق اتساق بلا اعتماديات خارجية.
- `.github/workflows/deploy-pages.yml` — التحقق والنشر إلى GitHub Pages.

## تحديث التقدم

عند إثبات إكمال درس أو بدء عنصر جديد، حدّث `docs/progress.json` و`LEARNING_PROGRESS.md` معاً في التغيير نفسه. ملف JSON هو المصدر المعتمد لحالة كل عنصر ودليله؛ ويجب أن يطابقه جدول الدروس المكتملة ورقم الدرس الحالي وتاريخ التحديث في Markdown.

شغّل المدقق قبل إرسال التغييرات:

```sh
node scripts/validate-progress.mjs
```

يتحقق المدقق من تسلسل الأرقام، وصحة الحالات والأنواع وترتيبها، ومتطلبات الدليل والمتبقي، وتطابق الدرس الحالي وصفوف `Complete` وتاريخ التحديث بين الملفين.

لا تغيّر حالة أي درس إلى مكتمل دون دليل فعلي على فهمه. في بداية كل مرحلة، ابدأ بمراجعة قصيرة من خمسة أسئلة تغطي الدروس السابقة.

## المعاينة المحلية

جهّز مجلد معاينة مطابقاً لأثر النشر ثم شغّل خادم ملفات ثابتاً:

```sh
mkdir -p _site _site/lessons
cp -R docs/. _site/
cp LEARNING_PROGRESS.md _site/LEARNING_PROGRESS.md
cp -R lessons/. _site/lessons/
python3 -m http.server -d _site
```

ثم افتح `http://localhost:8000`. لا يوجد تثبيت حزم أو أداة بناء. هذه الخطوات تنسخ محتوى الدروس إلى مسار الموقع حتى تعمل صفحة التعلّم محلياً كما تعمل على GitHub Pages.

## النشر

فعّل GitHub Pages من **Settings → Pages → Build and deployment → GitHub Actions**. يقوم workflow بالتحقق من التقدم عند `push` إلى `main` أو عند فتح Pull Request على المسارات المحددة. بعد نجاح التحقق، ينشر تغييرات `main` أو التشغيل اليدوي عبر `workflow_dispatch` إلى GitHub Pages. لا ينفّذ النشر في أحداث Pull Request.

رابط الموقع: https://pandurodev.github.io/rustpath-for-me-/


## طريقة التعلّم داخل الموقع

يفتح المتعلم الدرس من لوحة RustPath، يقرأ وحدات قصيرة، ثم يحل التطبيق والاختبار داخل الصفحة. الدرس الرابع يستخدم محاكاة PowerShell آمنة لا تنفذ أوامر على جهاز المتعلم. تحفظ المحاولة محلياً في المتصفح ويمكن تنزيل تقريرها. لا يغيّر ذلك سجل الإنجاز الرسمي؛ فلا يُحدّث السجل إلا بعد مراجعة دليل المحاولة.

## قابلية التكامل مع وكلاء الذكاء الاصطناعي

هذه مرحلة مستقبلية وليست جزءاً من التنفيذ الحالي. لن نضيف الآن واجهة تحكم عن بعد أو API أو صلاحيات كتابة للوكيل. عند الوصول إلى هذه المرحلة، سيُصمم عقد واضح ومحدود للقراءة والتفاعل مع الدروس، مع إبقاء صلاحيات تعديل سجل التقدم منفصلة ومحمية.
