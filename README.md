# FUCKING-RUST

منهج عملي لتعلّم Rust من الصفر، مع سجل تقدّم ولوحة متابعة عربية.

## متابعة التعلّم

- **سجل التقدم المعتمد:** [LEARNING_PROGRESS.md](./LEARNING_PROGRESS.md)
- **لوحة المتابعة:** [فتح لوحة المتابعة](https://pandurodev.github.io/FUCKING-RUST/) ([ملفات المصدر](./docs/index.html))

تعرض لوحة المتابعة المرحلة الحالية والدروس المكتملة والدرس التالي. التصميم مستوحى من مبادئ Uber البصرية: واجهة بسيطة، تباين واضح، ألوان محدودة، ومساحات مرتبة، دون إضافة إطار عمل ثقيل.

## تشغيل الموقع

الموقع ثابت ولا يحتاج إلى بناء:

1. افتح إعدادات المستودع في GitHub.
2. انتقل إلى **Settings → Pages**.
3. اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/docs`.
5. احفظ الإعدادات وانتظر نشر GitHub Pages.

بعد النشر سيكون الرابط عادةً:
`https://pandurodev.github.io/FUCKING-RUST/`

## ملاحظة حول حفظ التقدم

ملف `LEARNING_PROGRESS.md` هو المرجع الرسمي للتقدم، ويُحدّث بعد إثبات إكمال الدرس. لوحة الموقع تعرض نسخة مرئية من الحالة المعتمدة. التفاعلات داخل المتصفح لا تحفظ تغييرات إلى GitHub تلقائيًا.

## قواعد المنهج

- الشرح بالعربية ومن الصفر.
- شرح المفهوم قبل استخدامه، وشرح الأكواد سطرًا بسطر.
- لا تُعطى حلول التمارين قبل محاولة المتعلم.
- لا يُعتبر الدرس مكتملًا بمجرد شرحه؛ يلزم تطبيق أو اختبار يثبت الفهم.
- إنشاء أول مشروع Rust مبكرًا في المرحلة الثانية بعد شرح Cargo، لا بعد إنهاء اللغة كاملة.
