# RustPath

منهج عملي لتعلّم Rust من الصفر، مع سجل تقدّم ولوحة متابعة عربية.

## متابعة التعلّم

- **سجل التقدم المعتمد:** [LEARNING_PROGRESS.md](./LEARNING_PROGRESS.md)
- **لوحة المتابعة:** [فتح لوحة المتابعة](https://pandurodev.github.io/rustpath-for-me-/) ([ملفات المصدر](./docs/index.html))

## النشر

الموقع ثابت، وملفات النشر موجودة في `.github/workflows/deploy-pages.yml`.

1. افتح **Settings → Pages**.
2. اختر **GitHub Actions** ضمن Build and deployment.
3. افتح تبويب **Actions** وتحقق من تشغيل workflow باسم **Deploy learning dashboard**.
4. بعد نجاحه سيكون الموقع على:
   https://pandurodev.github.io/rustpath-for-me-/

اختيار GitHub Actions وحده لا يشغّل عملية نشر؛ يجب أن يعمل الـ workflow نتيجة دفع تغيير إلى `main` أو تشغيله يدوياً من تبويب Actions.

## سجل التقدم

ملف `LEARNING_PROGRESS.md` هو المرجع الرسمي للتقدم، ويُحدّث بعد إثبات إكمال الدرس. لوحة المتابعة تعرض نسخة مرئية من الحالة المعتمدة، ولا تحفظ التعديلات إلى GitHub تلقائياً.

## قواعد المنهج

- الشرح بالعربية ومن الصفر.
- شرح المفهوم قبل استخدامه، وشرح الأكواد سطراً بسطر.
- لا تُعطى حلول التمارين قبل محاولة المتعلم.
- لا يُعتبر الدرس مكتملاً بمجرد شرحه؛ يلزم تطبيق أو اختبار يثبت الفهم.
- إنشاء أول مشروع Rust مبكراً في المرحلة الثانية بعد شرح Cargo.
