# RustPath

مسار عربي منظّم لتعلّم Rust، من أساسيات البرمجة إلى المشاريع العملية.

**الموقع:** https://pandurodev.github.io/rustpath-for-me-/

## الفكرة

كل صفحة في الموقع تُبنى تلقائيًا من ملف Markdown. لا تُكتب صفحات الدروس يدويًا، ولا تحتاج إلى تعديل HTML عند إضافة درس.

- **لوحة التعلّم** تعرض المراحل والدروس والدرس الحالي.
- **صفحة كل مرحلة** تعرض دروسها بالترتيب.
- **صفحة كل درس** تعرض الشرح والأمثلة، ثم كتلة الملاحظات والتدريب، ثم الاختبار.
- **سجل التقدم** يعرض الحالة الرسمية للدروس من ملفات المحتوى.

المحتوى هو المصدر الوحيد للحقيقة. الحالة الرسمية للدرس مكتوبة في أعلى ملف الدرس (`status`)، وتقدمك في الاختبارات يُحفظ في متصفحك فقط.

## الحالة الحالية

- 6 مراحل و43 درسًا في المنهج.
- الدروس 1–4 جاهزة المحتوى، وكلها تبدأ بحالة `upcoming` كي ينطلق التقدم من الصفر.
- الدروس 5–43 مهيأة كمسودات، وتظهر بصفحاتها مع تنبيه «قيد الإعداد».
- كل درس جاهز يحتوي شرحًا وأمثلة واختبارًا وأسئلة متنوعة.

## كيف تضيف درسًا؟

1. افتح ملف الدرس في مجلد `content/lessons/` على GitHub.
2. عدّل بيانات الأعلى (العنوان والملخص والحالة)، ثم اكتب الشرح والأمثلة.
3. أضف كتلة اختبار `:::quiz` وأسئلتها، أو استخدم أي كتلة جاهزة أخرى.
4. ارفع التغيير إلى `main`. سيتولى GitHub Actions الاختبار والبناء والنشر تلقائيًا.

لا تحتاج إلى تثبيت أي شيء على جهازك، ولا إلى تشغيل موقع محلي. افتح رابط الموقع بعد اكتمال النشر.

**دليل الكتل والصياغة الكامل:** [content/README.md](content/README.md)

## بنية المشروع

```text
content/
  README.md        دليل كتابة المحتوى
  images/          الصور المستخدمة داخل الدروس
  stages/          ملفات المراحل
  lessons/         ملفات الدروس
site/
  assets/          CSS وJavaScript
  favicon.svg
scripts/
  lib/markdown.mjs تحليل Markdown والكتل
  lib/content.mjs  تحميل المحتوى والتحقق منه
  build.mjs        بناء موقع ثابت داخل _site
  serve.mjs        معاينة محلية بلا اعتماديات

.github/workflows/ بناء ونشر GitHub Pages
```

## الكتل الجاهزة

| الكتلة | الاستخدام |
| --- | --- |
| `:::quiz` | رأس مجموعة اختبار وحد النجاح |
| `:::single` | سؤال اختيار من متعدد بإجابة واحدة |
| `:::multiple` | سؤال متعدد الإجابات |
| `:::truefalse` | سؤال صحيح/خطأ |
| `:::short` | إجابة قصيرة تُصحح تلقائيًا |
| `:::long` | إجابة مكتوبة مع إجابة نموذجية |
| `:::notes` | مساحة ملاحظات محفوظة محليًا |
| `:::checklist` | قائمة مهام تفاعلية محفوظة محليًا |

جميع الكتل موثقة مع أمثلة جاهزة في [content/README.md](content/README.md).

## التطوير المحلي (اختياري)

المشروع بلا اعتماديات npm. يحتاج فقط إلى Node.js 22 أو أحدث:

```powershell
npm run build     # بناء _site
npm test          # 12 اختبارًا
npm run preview   # بناء ثم معاينة على http://localhost:4173
```

تستطيع أيضًا تشغيل الخطوات مباشرة:

```powershell
node scripts/build.mjs
node --test tests/markdown.test.mjs tests/build.test.mjs
```

مجلد `_site` هو الناتج، وهو مستبعد من Git. النشر الفعلي يتم من GitHub Actions.

## ملاحظات

- الموقع عربي أولًا باتجاه RTL. الحقول الإنجليزية القديمة لم تُعد مصدرًا للعرض.
- محاكي الطرفية القديم استُبدل بكتلة تدريب تفاعلية ومساحة ملاحظات، لأن النظام الجديد يركّز على كتل Markdown القابلة لإعادة الاستخدام.
- حالة الاختبارات محلية في المتصفح، ولا تغيّر حالة الدرس الرسمية تلقائيًا. لتغيير الحالة الرسمية، عدّل `status` في ملف الدرس.

## الاعتمادية والوصولية

- الخطوط تُحمّل من Google Fonts، وإن تعذّر التحميل يعمل الموقع بخط Arial.
- الأيقونات زخرفية (`aria-hidden`) والنص بجانبها يبقى ظاهرًا دائمًا.
- تلوين الكود عبر Prism من CDN؛ عند تعذّره يظهر الكود كنص عادي مقروء.
- نتائج الاختبار مكتوبة نصيًا («إجابة صحيحة» / «إجابة غير صحيحة») وتُعلن لقارئ الشاشة، وليست ألوانًا فقط.
- كل الروابط والأزرار لها مؤشر تركيز واضح للوحة المفاتيح، وصفحة 404 تعيدك إلى المحتوى.
