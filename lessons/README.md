# ملفات الدروس

يُحفظ المحتوى الأساسي لكل درس في ملف منظم داخل هذا المجلد. الصيغة المفضلة للدروس التفاعلية هي JSON باسم:

`lesson-NN-slug.json`

مثال: `lesson-04-terminal-and-paths.json`.

## بنية الدرس

يحتوي ملف الدرس على:
1. **البيانات الأساسية** — رقم الدرس والعنوان والملخص بالعربية والإنجليزية.
2. **الأهداف** — نتائج تعليمية واضحة وقابلة للتحقق.
3. **الوحدات** — شرح متدرج، أمثلة، ونقاط أساسية.
4. **التطبيق** — مهمة عملية وخطواتها وبيئة تدريب محددة إن احتاج الدرس إلى محاكاة.
5. **الاختبار** — أسئلة ذات إجابات محددة وتغذية راجعة وتلميحات.
6. **الإصدار** — رقم نسخة للمخطط حتى يمكن تطوير المحتوى دون كسر القارئ.

## قواعد التدريس

- يُعرض الشرح داخل الموقع، لا في المحادثة.
- لا تكشف الإجابات قبل محاولة المتعلم.
- اجعل التمرين عملياً، ويفضل أن يحل المتعلم داخل الصفحة عندما يكون ذلك ممكناً وآمناً.
- لا تنفّذ محاكاة الأوامر أي تعليمات على جهاز المستخدم.
- لا يُعد الدرس مكتملاً بمجرد القراءة أو فتح الصفحة؛ يجب اجتياز التطبيق والاختبار وتقديم دليل.
- لا تغيّر حالة التقدم الرسمية تلقائياً من Local Storage. سجل الإنجاز المعتمد يُحدّث بعد مراجعة الدليل.

تُنسخ ملفات الدروس المطلوبة إلى `_site/lessons/` ضمن Workflow النشر. يجب إضافة أي ملف جديد إلى فحص البنية في `scripts/validate-lessons.mjs` عند الحاجة.
