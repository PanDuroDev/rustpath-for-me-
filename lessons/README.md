# ملفات الدروس

يُحفظ كل درس في ملف مستقل داخل هذا المجلد بالصيغة التالية:

`lesson-NN-slug.md`

- `NN` رقم الدرس المكوّن من خانتين، مثل `04`.
- `slug` وصف قصير بالإنجليزية يفصل بين كلماته بشرطة، مثل `terminal-and-paths`.

## أقسام ملف الدرس

يحتوي كل ملف على الأقسام التالية وبالترتيب:

1. **الهدف** — ما الذي ينبغي أن يفهمه المتعلم أو يستطيع تنفيذه بعد الدرس.
2. **الشرح** — شرح المفهوم من الأساس وبالعربية، مع توضيح المصطلحات الجديدة.
3. **الأمثلة** — أمثلة صغيرة مشروحة خطوة بخطوة.
4. **التمرين** — مهمة تطبيقية يحاول المتعلم حلها بنفسه.
5. **الاختبار** — خمسة أسئلة قصيرة للتحقق من الفهم.

لا يُعد الدرس مكتملاً بمجرد قراءة الشرح؛ يجب تسجيل دليل يثبت المحاولة والفهم في `docs/progress.json` و`LEARNING_PROGRESS.md` معاً.
